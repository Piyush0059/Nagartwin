# Piyush Kumar — The Build Log

**Live preview:** https://piyush0059.github.io/Nagartwin/portfolio/  
**Portfolio source:** https://github.com/Piyush0059/Nagartwin/tree/main/portfolio

A standalone static portfolio in `index.html`. The page uses inline CSS and JavaScript, so it needs no package installation, build process, external image assets, API key, or server.

## What is included
- Cinematic opening sequence and three viewing lenses (Builder, Investigator, Humanist)
- Responsive hero and custom CSS artwork
- Featured rail and six interactive project case studies
- Category filters, keyboard quick-jump (`Ctrl+K` / `⌘K`, or `/`), Escape-to-close dialogs, and mobile navigation
- Short story reel, responsive timeline, learning section, contact links, and reduced-motion support
- Project status notes that distinguish a live demo from experimental prototypes

## Publish
This folder is served as a subdirectory of the existing NagarTwin GitHub Pages site at `/Nagartwin/portfolio/`. All code is contained in `index.html`; the parent project's root page is unchanged.
